# Begin and recover an exact 4-player compact shared Basic table

Configure at 1440 × 1000, then review the same started table at 1280 × 720 and return to the original viewport for mat inspection. One shared display and one controller configure 4 named physical seats directly on the table. Factions, settings, starting-player order and Begin use ordinary production controls. No remote identities or companion devices. Command entropy is fixed before play, without injecting any game state. The story stops at the real immutable starting position.
