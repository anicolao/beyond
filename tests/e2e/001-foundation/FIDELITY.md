# Foundation visual review

References: [arrival concept](../../../docs/ux/concepts/01-arrival.png), [shared-table contract](../../../UX_DESIGN.md#shared-table-mode), and Pantheon's direct edge joining.

The production scene uses original observatory art, bundled Cormorant/Atkinson fonts, semantic controls, bronze edges, and teal feedback. It does not use a flattened concept plate as UI.

The revised evidence consists of three production stories and seven viewport runs: arrival/turn guide at phone, desktop and 4K; physical-seat configuration at desktop and 4K; and PR/production recovery at desktop and 4K. There are 85 ordered captures per platform. All meaningful editor, name, join, first-player, edit, leave and recovery changes are illustrated. The old naming/save/result story and its baselines have been removed.

Reviewed macOS captures show eight distinct physical positions with controls facing the person sitting there, names edited at those positions, clockwise turn order, four-player capacity, and preserved configuration after reload. Empty seats remain visible while gathering and become unavailable at capacity. Opening recovery replaces the central gathering text with a bounded version-switch panel, leaving seat controls visible. The phone guide keeps all three phases readable within 393 × 852. The shared table is tested on shared-display viewports, not presented as remote phone PvP.

Scope: this is the actual gathering table; faction setup, boards and gameplay extend it in later milestones. There is no temporary name wizard, Save table, saved result, placeholder Begin, tabletop QR, or companion screen. The production backdrop remains readable behind eight seat surfaces. Components, commands and the canonical event stream are retained as capabilities grow.

The recovery story builds two real clients at separate deployment paths on one origin, uses the table's ordinary recovery controls, changes a name through production, and sees the change through the PR client. Both use the same emulator game and browser identity. Hosted production is first published when this scaffold merges; no unmerged client is substituted at the production URL.

Exact image hashes are recorded in BASELINES.sha256. Linux captures were generated by run 39142575494 in the pinned ARM64 Playwright 1.61.1 Noble image. Reviewed the seated/renamed 4K table, North inline editor, recovery picker with a visible focus ring, and phone Learn composition against the macOS evidence. Seat orientation, text, targets and bounded recovery controls match the production design; generation is distinct from the subsequent comparison gate.
